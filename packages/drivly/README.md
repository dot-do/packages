# Drivly SDK

```bash
yarn add drivly
```

Then you can use the SDK:

```javascript
import { makes } from 'drivly'

console.log({ makes })
```

But if you prefer, you can also HTTP Import:

```javascript
import { makes } from 'https://pkg.do/drivly'

console.log({ makes })
```
